# Course Domain Model

## TrackConstructor
Отвечает за сборку и структуру курса.

## Material
Атомарная единица контента:
- текст
- видео
- квиз

## Track
Курс целиком.
Содержит полный DSL / текст курса.

## TrackMaterial
Связь многие-ко-многим между Track и Material.
Отвечает за порядок отображения.
